About this doc set

Every product page follows the same structure: L100 (what it is) → L200 (product surface) → L300 (architecture) → L400 (deep internals) → Anti-patterns → Weaknesses → Sources. Cross-cutting terms are defined once in the Glossary.

To add or edit a product: edit _control.yaml (set status: pending or needs-update), then re-run the regeneration prompt described at the bottom of the control file.
