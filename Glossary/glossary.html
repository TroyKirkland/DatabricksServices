Compute & runtime

Classic compute
Spark clusters that you size and that run inside your cloud VPC/VNet. Slower to start, supports init scripts and custom libraries. Required for ingestion gateways and some legacy workloads.
Cluster
Driver + worker VM group running Spark. Single-node, multi-node, or pool-backed. Has a DBR version.
Databricks Connect
Client library to talk to a remote Databricks cluster from a local IDE via Spark Connect.
Databricks Runtime (DBR)
Versioned bundle of Spark + Photon + ML libraries + cloud SDKs. LTS releases supported ~3 years (36 months). ML and GPU variants.
DBU (Databricks Unit)
Billing unit. Different SKUs (Jobs, All-Purpose, SQL, LDP, Serverless) have different DBU rates.
Photon
Databricks' C++ vectorized execution engine. Engages automatically for supported SQL/DataFrame operators; falls back to JVM Spark otherwise.
Pool
Pre-warmed VMs clusters can draw from to skip cold-start.
Serverless compute
Databricks-managed compute that runs in Databricks' account. Scale-to-zero, fast startup. Available for SQL Warehouses, Jobs, Notebooks, LDP, Model Serving.
Spark Connect
Client/server protocol decoupling Spark client code from the JVM driver. Underpins Databricks Connect.
SQL Warehouse
SQL-only compute endpoint. Three flavors: Serverless (fastest, Databricks-managed), Pro (in your VPC, advanced governance), Classic (legacy).

Storage, format, governance

ACID
Atomic-Consistent-Isolated-Durable transactions. Delta provides ACID at the table level via the transaction log.
CDF (Change Data Feed)
Delta feature exposing per-row change events with _change_type.
Column mapping
Delta feature decoupling logical names from physical Parquet field IDs. Required for renames.
Delta Lake
Open transactional storage on Parquet with a JSON+checkpoint transaction log in _delta_log/.
Delta Sharing
Open protocol for sharing Delta tables across orgs/clouds without copy. D2D (Databricks-to-Databricks) richer than D2O (open-source, now branded OpenSharing).
Delta UniForm
A Delta table that simultaneously exposes Iceberg metadata (IcebergCompatV2) for non-Databricks readers. Iceberg-only (Hudi output removed).
Deletion vector
Soft-delete metadata marking Parquet rows deleted without rewriting the file.
External location
UC object pointing at a cloud-storage prefix with a storage credential.
External table
UC table whose data lives outside the metastore-managed root.
Hive Metastore (HMS)
Legacy per-workspace metastore. Avoid for new work.
Liquid clustering
Delta layout strategy that auto-clusters on declared columns; supersedes PARTITIONED BY and ZORDER for most cases. Supports hierarchical clustering and partial reclustering (OPTIMIZE … FULL).
Managed Iceberg table
UC managed table stored in Apache Iceberg format (GA 2026), governed like a managed Delta table. Distinct from UniForm (Iceberg metadata over Delta files).
Managed table
UC table whose data lives in the metastore-managed root. UC owns the files' lifecycle.
Metastore
UC's top-level catalog container, one per region per account.
OpenSharing
Databricks' name for sharing with non-Databricks recipients over the open Delta Sharing protocol (incl. an Iceberg REST Catalog API). The open-recipient path formerly described as D2O.
OPTIMIZE
Delta command that compacts small files; with ZORDER or liquid clustering, also reorganises layout.
Predictive optimization
UC feature that auto-runs OPTIMIZE/VACUUM/ANALYZE on managed tables. Enabled by default for accounts created on/after Nov 2024.
RBAC (Role-Based Access Control)
UC capability (GA 2026) letting a user assume a named role scoped to only that role's privileges. Complements ABAC.
Row filter / column mask
UC functions applied at query time to filter rows or mask cells based on caller identity/attributes.
Row tracking
Delta feature assigning a stable _metadata.row_id and row_commit_version per row for row-level lineage. GA since DBR 14.0.
Schema (UC sense)
Mid-tier namespace inside a catalog: <catalog>.<schema>.<table>.
Storage credential
UC object wrapping an IAM role / managed identity for cloud storage access.
System tables
UC system.* catalog exposing billing, audit, lineage, query history.
Time travel
Querying a Delta table at a prior version or timestamp. Bounded by VACUUM retention.
Type widening
Delta schema-evolution feature that widens a column's type (e.g. int→long) without rewriting files. GA since DBR 15.4 LTS; bounded to a defined set of widening paths.
Unity Catalog (UC)
Databricks' unified governance plane for tables, models, volumes, ML assets; lineage, audit, ABAC, fine-grained access control.
UC Volume
Governed non-tabular storage abstraction. Path scheme /Volumes/<catalog>/<schema>/<volume>/....
VACUUM
Delta command that physically removes files no longer in the latest version after retention.
Z-order
Multi-dimensional Delta data-skipping ordering. Largely superseded by liquid clustering.

Streaming & change capture

APPLY CHANGES INTO
LDP statement that applies a CDC change feed to a streaming table; supports SCD Type 1 or 2. Superseded by AUTO CDC (older API still functions, no longer recommended).
AUTO CDC
Current LDP API that replaced APPLY CHANGES INTO for applying a CDC feed to a streaming table. AUTO CDC FROM SNAPSHOT (Python) compares sequential full snapshots. Supports bitemporal SCD Type 2.
Auto Loader
cloudFiles Structured Streaming source for incremental file ingestion. Directory listing or file-notification modes (incl. file events mode).
CDC (Change Data Capture)
Source-DB mechanism emitting insert/update/delete events with column-level history. Heavier than Change Tracking.
Change Tracking (SQL Server)
Lightweight SQL Server feature recording which rows changed (no values). Lower source overhead than CDC.
File events mode
Auto Loader file-notification sub-variant (cloudFiles.useManagedFileEvents=true, DBR 14.3 LTS+) using a Databricks-managed shared queue per UC external location; no per-stream cloud IAM.
Idempotent write
Write that produces the same final state regardless of replay. AUTO CDC is idempotent on its sequence key.
LSN (Log Sequence Number)
Monotonic position in a source's transaction log. GTID for MySQL, SCN for Oracle, WAL LSN for Postgres.
Materialized view (MV)
Refreshable result-cached table in LDP or DBSQL.
SCD Type 1 / Type 2
Slowly-changing-dimension patterns. Type 1 = current state; Type 2 = row-per-version with __START_AT/__END_AT.
Streaming table (ST)
Delta table written incrementally by a streaming source; declared in LDP or DBSQL.
Structured Streaming
Spark's streaming framework. Underpins Auto Loader, LDP streaming tables, and most Databricks streaming.
Zerobus
Databricks' gRPC ingest SDK writing directly to Delta without a message-bus hop.

Orchestration & deployment

Declarative Automation Bundles (DAB)
YAML-defined deployable bundle of jobs/pipelines/dashboards/apps. databricks bundle deploy. Formerly Databricks Asset Bundles.
Job (Lakeflow Job)
Orchestration unit with tasks, dependencies, triggers, retries, notifications.
Notebook
Mixed-language interactive document (Python/SQL/Scala/R).
Repos / Git folder
Workspace folder synced to a Git remote.
Service principal
Non-human identity. OAuth, PAT, or federated auth.
Task
One step in a Job: notebook, wheel, JAR, SQL, dbt, LDP pipeline trigger, for-each.
TaskValues
Key-value payload one task publishes for downstream tasks to read.
Trigger
How a Job starts: scheduled, continuous, file arrival, table update.

SQL & analytics

AI/BI Dashboards
Successor to Lakeview; native dashboarding inside Databricks.
AI/BI Genie
NL-to-SQL conversational interface scoped to a Genie Agent.
Catalog Federation
Lakehouse Federation mode giving direct object-storage access to foreign catalogs (Glue, external/legacy Hive metastore, Salesforce Data 360, Snowflake, Palantir Foundry, Workday) without a JDBC hop; auto-refreshes at query time.
DBSQL
Databricks SQL: warehouses, queries, dashboards, alerts.
Genie Agent
Bounded set of tables + instructions + example SQL (and optional metric views) an LLM uses to answer questions. Formerly Genie Space; end-user NL interface is Genie One.
Lakehouse Federation
UC foreign catalogs proxying queries to Snowflake, Postgres, SQL Server, BigQuery, Redshift, MySQL, Oracle, Teradata. Two modes: Query Federation (JDBC) and Catalog Federation (direct storage).
Lakeview
Legacy name for AI/BI Dashboards.
Materialized view
In DBSQL, an MV refreshed by a serverless pipeline behind the scenes.
Metric View
UC semantic-layer object defining reusable business measures and dimensions, queryable via the MEASURE aggregate and usable as a dashboard/Genie dataset.
Pipe syntax (|>)
DBSQL operator-chained SQL alternative to nested subqueries.
Query Federation
The original Lakehouse Federation mode: JDBC pushdown to live external databases (Snowflake, Postgres, SQL Server, BigQuery, Redshift, MySQL, Oracle, Teradata); requires manual schema refresh.
Statement Execution API
REST API to submit SQL to a warehouse without JDBC/ODBC.

AI / ML

Agent Bricks
Eval-driven agent builder: Knowledge Assistant, Genie Agent, Multi-Agent Supervisor.
ChatAgent / ResponsesAgent
MLflow agent interfaces for serving conversational/agentic models with tracing.
External model
Model Serving endpoint proxying to outside provider (OpenAI, Anthropic, Cohere, Bedrock). Subject to Unity Gateway policies.
Feature Store / Feature Engineering in UC
Feature tables in UC + online tables; point-in-time joins for training-serving parity.
Feature Views
Public-Preview declarative feature definitions in Feature Engineering (DeltaTableSource, StreamSource, RequestSource). DBR 17.0 ML+ or serverless.
Foundation Model APIs (FMAPI)
Databricks-hosted foundation models. Pay-per-token or Provisioned Throughput.
Full-Text Search Index
Vector Search index type (Beta) doing BM25 keyword search on text columns with no embeddings; storage-optimized endpoints, triggered sync only.
Logged Models
MLflow 3 first-class entity tracking a model's development arc (runs, metrics, params, code); distinct from a UC registered model version.
MCP server (Model Context Protocol)
Standardised tool/API interface agents call to reach external systems; a resource type for Apps, DABs, and Agent Bricks MAS, governed by Unity Gateway.
MLflow
OSS experiment tracking + model registry + tracing + evaluation. Registered models live in UC on Databricks.
Model Serving endpoint
Hosted inference endpoint. Serverless, scale-to-zero, GPU-optional.
Mosaic AI
Umbrella brand for Model Serving, Vector Search, Unity Gateway, Agent Bricks, FMAPI.
Online table
Low-latency replica of a Delta feature table used at inference time (backed by Lakebase Autoscaling).
Pay-per-token
FMAPI billing model: per input+output token on shared infra.
Payload table
Auto-generated Delta table of Model Serving request/response logs.
Provisioned Throughput
FMAPI billing model with reserved dedicated capacity.
Reciprocal Rank Fusion (RRF)
Algorithm Vector Search hybrid queries use to merge vector + keyword result sets; hybrid results capped at 200.
Unity Gateway
Governance/policy layer in front of model endpoints, agents, and MCP servers: rate limits, PII detection, payload logging, fallback and smart routing. Formerly Mosaic AI Gateway.
Vector index
Mosaic AI Vector Search index over a column of embeddings; optionally Delta-synced.

Apps & operational data

app.yaml
Manifest for a Databricks App declaring command, resources, scopes.
Databricks App
Hosted Streamlit/Dash/Flask/FastAPI/Node web app inside Databricks with workspace OAuth.
Lakebase
Managed Postgres on Databricks; provisioned and autoscale flavors; branching, scale-to-zero.
Marketplace listing
Data product, AI model, or notebook published in Databricks Marketplace; Delta-Sharing delivery.

Networking & identity

OAuth M2M / U2M
Machine-to-machine (service principal) vs user-to-machine (interactive) OAuth flows.
Private Link
Cloud-provider private endpoint to reach Databricks control plane and storage privately.
SCIM
Identity sync protocol for users/groups from your IdP into Databricks.

Delta Live Tables (DLT)
Renamed to Lakeflow Spark Declarative Pipelines (LDP).
Workflows
Renamed to Lakeflow Jobs.
Lakeview
Renamed to AI/BI Dashboards.
Feature Store (workspace)
Migrated to Feature Engineering in Unity Catalog.
Databricks Asset Bundles
Renamed to Declarative Automation Bundles (DAB).
Mosaic AI Gateway
Renamed to Unity Gateway.
Genie Space
Renamed to Genie Agent (end-user interface: Genie One).
