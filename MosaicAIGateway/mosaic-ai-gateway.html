L100What it is

Policy + observability layer in front of model endpoints, AI agents, and MCP servers. Centralises rate limits, budget management, PII detection, payload logging, fallback + smart routing, and cost tracking. Apps call one governed endpoint regardless of the underlying model or agent.

  • One pane for many models and agents (GPT/Claude/Gemini/Llama + custom + agents + MCP).
  • Governance: rate limits, budget caps, PII, audit; extends to runtime agent/tool interactions.
  • Resilience: fallback, retry, traffic split, smart routing.

L200The product surface

  • Gateway-enabled endpoint (per-endpoint or workspace-wide).
  • Rate limits + budget caps by identity/endpoint/tokens.
  • PII detect/redact/block.
  • Service policies / guardrails (input + output): prompt-injection, toxicity, block-lists, custom.
  • Fallback routing on error/timeout/rate-limit.
  • Smart routing: auto model selection for task types (e.g., coding) to reduce cost.
  • Payload log → Delta table.
  • Usage in system.serving.*.
  • Agents + MCP servers: UC GRANT-based access control at runtime.
  • UI + REST + DABs config.

L300Architecture

[Caller] → [Gateway-enabled endpoint]
            ↓ request pipeline: authZ → rate limit → PII → guardrail → route
            ↓
            [Model: FMAPI / external / custom]
            ↓ response pipeline: guardrail → PII scrub → payload log → usage emit
            ↓
          [Caller]

All requests + streaming go through. Fallback evaluated on error/timeout. Payload table written async.

L400Deep internals

Rate limits

  • Token + request based.
  • Per principal / endpoint / route.
  • Retry-After headers.
  • Sliding window typical.

PII detection

  • Categories (PHONE, EMAIL, SSN…). Modes: detect / redact / block.
  • Defense layer, not guarantee.

Guardrails

  • Built-in: prompt-injection, toxicity, profanity, block-list.
  • Custom: regex / SQL UDF.
  • Input + output.

Fallback routing

  • Ordered served entities. Triggers: 5xx, rate-limit, timeout.
  • Streaming: only fallback at session start, not mid-stream.

Payload tables

  • UC Delta: request/response/latency/status/identity/tokens/PII/fallback.
  • Sampling configurable.

Usage + cost

  • system.serving.endpoint_usage tokens.
  • Joinable with system.billing.usage.
  • Per-principal via payload identity.

External model semantics

  • UC-stored creds.
  • Optional schema unification (OpenAI/Anthropic).
  • Extra hop = small latency cost.

Streaming

  • SSE supported.
  • End-of-stream token counts + final guardrail.
  • Mid-stream moderation limited.

Multi-endpoint / shared

  • Workspace-wide defaults + per-endpoint overrides.

Limits / realities

  • Burst over-shoot possible.
  • PII false +/- both happen.
  • Payload table size growth.
  • Slight added latency.
  • External provider quotas still apply.

Smart routing

  • Auto-selects cheaper/efficient model for specific task types (e.g., coding); reduces spend without manual routing logic.
  • Databricks-managed selection logic; not a general routing DSL.

Mental model

"Smart proxy for model endpoints, agents, and MCP tools." Apigee/Cloudflare role tuned for LLM specifics (tokens, PII, prompt injection), extended to the full agentic runtime.

Anti-patternsWhere you should not use Gateway

  • Trivial single-model internal deployment.
  • Trust PII detection as sole defense.
  • Complex custom routing.
  • Mid-stream content moderation expectations.
  • Replacing external provider quotas.
  • Microservice/non-LLM routing.
  • High-throughput edge inference.
  • No payload table cost plan.
  • Cross-org collaboration. Use Clean Rooms.
  • As an agent framework. Use Agent Bricks / LangGraph.

WeaknessesWhere it does not do well

  • PII false +/-.
  • Limited guardrail customisation.
  • Streaming guardrail blind spot.
  • Policy hierarchies basic.
  • Rate-limit isn't strict-realtime.
  • No native dashboards.
  • SQL-driven cost attribution.
  • External header pass-through lossy.
  • Latency overhead on small calls.
  • Streaming mid-call failover hard.
  • Per-region scope.
  • Basic policy testing tools.
